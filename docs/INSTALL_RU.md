# 🛠 Установка PadKey Mapper (RU)

## ⚠️ ВНИМАНИЕ:
    * Для работы программы необходимо запустить модуль ядра `uinput`!!!
        - Для этого необходимо выполнить эту команду в терминале:
            ```bash
            sudo modprobe uinput
            ```
        - Обычно программа сама об этом сообщает, если не находит модуль. Но если вдруг нет - сначала попробуйте выполнить эту команду прежде чем писать Issue.

## Универсальный AppImage

Для работы программы требуется доступ к подсистеме ядра `uinput` (для эмуляции нажатий клавиш) и доступ к USB-устройствам MIDI.

1. Скачайте последний файл `.AppImage` из раздела [Releases](https://github.com/Y-Akamirsky/PadKeyMapper/releases).

    * *Linux по умолчанию запрещает приложениям создавать виртуальные клавиатуры. Нам нужно создать правило `udev`.*

2. Откройте терминал и запустите скрипт настройки udev правила из удаленного репозитория:
    ```bash
    curl -sL https://raw.githubusercontent.com/Y-Akamirsky/PadKeyMapper/refs/heads/main/install_uinput.sh | bash
    ```
3. Перезагрузитесь или выйдите и войдите в сессию (перезапуск сессии)
    * (Если не запускается после настройки и выхода из системы/перезагрузки) Используйте следущие команды для исправления прав у исполняемого файла:
    ```bash
    # Измените путь на ваш актуальный до пакета!!!
    cd /directory/of/your/appimage/
    # Замените {version} на актуальную версию пакета!!!
    chmod +x PadKeyMapper-{version}-x86-64.AppImage
    cd
    ```
    * **ВНИМАНИЕ:** Измените путь в командах на ваш актуальный до пакета и {version} на актуальную версию пакета!!!

## Нативный пакет для Arch Linux (.pkg.tar.zst)

Есть два пути: Установить готовый пакет из [релизов](https://github.com/Y-Akamirsky/PadKeyMapper/releases) или собрать из исходников.

* **Установка из** [релиза](https://github.com/Y-Akamirsky/PadKeyMapper/releases)
    
    1. Скачайте последний релиз в формате .pkg.tar.zst
    2. Установите пакет используя:
    ```bash
    # Замените путь на ваш актуальный!!!
    sudo pacman -U /путь/до/пакета/ИмяПакета.pkg.tar.zst
    ```
    3. **ВАЖНО:** Добавляем пользователя в группу uinput
    ```bash
    sudo usermod -aG uinput $USER
    ```
    4. Перезагрузитесь или выйдите и войдите в сессию (перезапуск сессии) для вступления изменений в udev в силу.
    
* **Сборка из исходников** (для продвинутых пользователей)
    
    1. Клонируйте репозиторий
    ```bash
    git clone https://github.com/Y-Akamirsky/PadKeyMapper
    ```
    2. Перейдите в директорию сборки build_arch/
    ```bash
    cd ~/PadKeyMapper/build_arch
    ```
    3. Запустите сборку
    ```bash
    makepkg -fsi
    # Флаги:
    # (-f) Ребилдит пакет даже если он уже существует.
    # (-s) Устанавливает необходимые зависимости
    # (-i) После сборки устанавливает пакет через sudo pacman -U
    ```
    4. **ВАЖНО:** Добавляем пользователя в группу uinput
    ```bash
    sudo usermod -aG uinput $USER
    ```
    5. Перезагрузитесь или выйдите и войдите в сессию (перезапуск сессии) для вступления изменений в udev в силу.
