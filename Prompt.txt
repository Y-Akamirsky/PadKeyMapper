Привет! Я разрабатываю Python-утилиту **PadKey Mapper (PKM)** для Linux (используя `uinput` и `mido`), которая позволяет маппить MIDI-события (Note On/CC) с Launchpad на нажатия клавиш клавиатуры.

**Цель утилиты:** Превратить Launchpad в настраиваемый макро-контроллер.

**Текущая структура программы:**
1.  **Главный файл:** `main.py` (содержит всю логику GUI `customtkinter`, `InputManager`, `MidiListenerThread`, и функции `load_config`/`save_config`).
2.  **Конфигурация маппингов:** `config.json` (хранит ID MIDI, назначенные клавиши и цвет подсветки).
3.  **Новый файл лейаутов:** `layouts.json` (создан, но не используется).

### 🎯 Текущая задача: Внедрение MIDI-лейаутов

Я хочу вынести фиксированные MIDI ID, используемые в GUI для кнопок (например, верхний ряд CC, боковые Note), в файл `layouts.json` для поддержки разных моделей Launchpad (Mini, X, Pro).

**Структура `layouts.json` должна быть следующей:**

```json
{
    "Launchpad Mini/MK2/X": {
        "cc_row_start": 104,
        "cc_row_end": 111,
        "side_notes": [8, 24, 40, 56, 72, 88, 104, 120]
    },
    "Launchpad Pro": {
        "cc_row_start": 91,
        "cc_row_end": 98,
        "side_notes": [9, 29, 49, 69, 89, 109, 129, 149]
    },
    "Default": {
        "cc_row_start": 104,
        "cc_row_end": 111,
        "side_notes": [8, 24, 40, 56, 72, 88, 104, 120]
    }
}

План действий, который нужно реализовать в main.py:

    Создать функцию load_layouts(filename="layouts.json"), которая загружает этот файл.

    В классе App добавить выпадающий список (OptionMenu) для выбора активного лейаута (self.active_layout_name). Использовать "Launchpad Mini/MK2/X" как дефолтный.

    Передать данные активного лейаута в конструктор EditMappingWindow.

    Обновить метод EditMappingWindow.create_widgets, чтобы он использовал данные из активного лейаута (cc_row_start, cc_row_end, side_notes) для генерации виртуального Launchpad (кнопок CC и боковых Note) в GUI.
